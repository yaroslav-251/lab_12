1. Для чего нужен `enum` и какую проблему решает использование именованных значений вместо чисел или строк?
Для создания набора именованных значений. Он делает код понятнее и помогает избежать ошибок при вводе чисел или строк.
2. Какие целочисленные значения по умолчанию получают элементы `enum`?
с 0: первый — 0, второй — 1, третий — 2 и так далее.
3. Что позволяет сделать `switch` с переменной типа `enum`?
ыполнять разные действия в зависимости от значения
4. Что означает `int?` и какое дополнительное состояние появляется у такой переменной по сравнению с обычным `int`?
тип, который может хранить целое число или null — отсутствие значения.
5. Чем отличаются `HasValue`, `Value` и оператор `??`?
HasValue проверяет наличие значения, Value получает его, а ?? подставляет значение по умолчанию, если значение равно null
6. В какой ситуации отсутствие значения является нормальным состоянием данных и поэтому `int?` удобнее обычного `int`?
Когда значение может отсутствовать, например если пользователь не указал его
7. Почему для класса персонажа лучше использовать `enum`, чем хранить `"Warrior"`, `"Mage"` и `"Archer"` в обычной строке?
Потому что enum ограничивает выбор значениями Warrior, Mage и Archer, снижая вероятность ошибок и упрощая проверку через switch
